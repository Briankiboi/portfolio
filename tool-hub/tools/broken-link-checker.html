⚙️How it works

Enter a page URL (fetched live from your browser) or paste the page's raw HTML. All external <a href> links are extracted, resolved against the base URL, then checked one by one with fetch — an HEAD request by default (falling back to GET on 405), with an 8-second timeout per link and a retry using no-cors when the browser's CORS policy blocks the normal request. Each link is grouped as Working, Redirect (e.g. 301/302), Broken (4xx/5xx or unreachable), or Blocked (timeout or CORS). Internal same-site links are skipped to keep runs fast, and the whole report can be exported as CSV.

🔒Privacy

Every request goes directly from your browser to the target site. There is no server, proxy, or log — nothing is stored or tracked.

💡Tips
  • When opened from file://, most sites block cross-origin reads — links then appear as "Blocked" but are still extracted so you can review them manually.
  • A blocked result is not the same as broken; it usually means CORS, not a dead page.
  • For the most accurate verification, serve this hub over http://localhost instead of opening files directly.
