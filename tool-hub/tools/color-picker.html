⚙️How it works

Drag the red, green, blue and alpha sliders (or type exact values) to build a colour. The panel updates live with the equivalent HEX, RGBA and HSLA codes, ready to copy into your CSS or design tool.

🔎Search & compare

Type a colour name (or a hex value) to find a match by name, then send any colour to A or B. The combination preview shows how the pair looks on a mock website, and the advice panel reports WCAG contrast ratios and suggests where to use each colour.

🎨Eyedropper

The “Pick a colour” button opens your system colour dialog, which in most modern browsers includes an eyedropper to sample a colour from anywhere on screen.

🔒Privacy

Everything runs in your browser — no colour is ever uploaded and nothing is stored about you.
