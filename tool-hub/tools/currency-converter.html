⚙️How it works

Twin tools on one page. On the left, the calculator does +  −  ×  ÷ with a phone-style keypad and previews the result live as you type — no need to press = (though it's there if you want it) — and feeds the grand total into the converter's Amount in real time. Below it, the split takes that grand total, deducts a share you enter (e.g. 30%), shows the deducted and remaining amounts, and splits what's left first by half (50 / 50) or into any custom shares you type below it (e.g. 45 / 55) — every value lands in the Amount field ready to convert. On conversion, the tool fetches a daily snapshot of mid-market rates (every supported currency measured against the USD base) from exchangerate-api.com, then computes your exact pair with a cross-rate: target ÷ source. The latest snapshot is cached in this device's localStorage, so already-seen pairs keep converting even offline.

🔒Privacy

Everything runs locally — your item lists, totals and share splits never leave the page. The only request is an anonymous currency lookup (no account, no key); just the currency symbols needed for the rate table are shared with the rate provider.

💡Tips
  • Use the keypad (or keyboard: + - * / Enter) — the result previews live; tap = only when you want to convert it.
  • Split a lunch, invoice or group bill: deduct a share (e.g. 30), tap Split by half for a quick 50 / 50 — or type custom shares like 45 and 55 below it and convert each tile.
  • Rates are indicative mid-market (daily); banks and card networks typically add their own margin on top.
  • Copy the result line anywhere — paste it into a doc or send it in a message.
