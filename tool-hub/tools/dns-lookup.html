⚙️How it works

Queries the public Google DNS-over-HTTPS API (dns.google/resolve, CORS-enabled) — the exact resolver behind 8.8.8.8. Pick a record type and the tool returns every matching record with its name, type, TTL and value. Supported types: A, AAAA, CNAME, MX, NS, TXT, SOA and ANY. Entered domains are cleaned automatically (strips http(s)://, www. and path).

🔒Privacy

Only the domain and record type you enter are sent to Google's resolver — no personal data — and nothing is stored or tracked.

💡Tips
  • TTL shows how long record values are cached; after DNS changes, allow up to the TTL for propagation.
  • Use MX to check email routing, TXT for SPF/DKIM/ownership tokens, and NS to confirm your nameservers.
  • ANY returns whatever the resolver happens to have cached for all types — for a complete answer, query each type you care about.
