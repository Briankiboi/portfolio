⚙️How it works

Fetches the page live (or parses HTML you paste) with DOMParser and runs a battery of on-page SEO checks locally: title length, meta description, keywords, canonical, H1/H2 usage, Open Graph, Twitter cards, JSON-LD structured data validity, robots meta, sitemap link, image alt completeness and more — each scored Pass / Warn / Fail with a weighted overall score and targeted fixes. To get the page, the tool first tries a direct fetch from your browser; when CORS blocks that, it automatically retries through a public CORS relay (r.jina.ai, then api.allorigins.win).

🔒Privacy

The page is fetched directly from your browser when possible — no server in between — and nothing is stored. Only when CORS blocks that does the tool relay the request through a public CORS relay, which simply forwards the page's HTML back to your browser. For a fully private path, paste raw HTML instead and nothing is sent at all.

💡Tips
  • The tool auto-retries through a public CORS relay when direct reads are blocked — if even that fails (or you want zero third-party contact), paste the page's raw HTML and re-run.
  • "Meta keywords present" shows a warning because Google has ignored that tag since 2009 — it's expected, not an error.
  • Fix Fail items first, then tackle Warn; the score updates as items pass.
