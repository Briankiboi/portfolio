⚙️How it works

Enter an https:// page URL or paste its raw HTML. The tool analyzes the page locally using DOMParser and checks important SEO elements, including:

  • Title length
  • Meta description
  • Canonical URL
  • Keywords
  • H1 and H2 headings
  • Open Graph and Twitter cards
  • JSON-LD structured data
  • Robots meta tag
  • Sitemap link
  • Image alt text

Each check is marked Pass, Warn, or Fail, with an overall SEO score and recommended fixes.

🔒Privacy

The page is fetched directly in your browser whenever possible, and nothing is stored. If browser security blocks the request, the tool may use a public CORS relay to retrieve the page.

For complete privacy, paste the raw HTML instead. The HTML is then analyzed locally without being sent anywhere.

💡Tips
  • Use an https:// URL for the most reliable results.
  • If fetching fails, paste the page’s raw HTML and run the analysis again.
  • “Meta keywords present” may show a warning because Google stopped using meta keywords for ranking in 2009. This is informational, not necessarily an error.
  • Fix Fail items first, then address Warn items to improve the score.
