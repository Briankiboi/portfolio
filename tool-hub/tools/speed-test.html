⚙️How it works

Uses the Fast.com / Netflix Open Connect methodology: opens parallel asynchronous data streams to the closest Cloudflare edge CDN node, discards TCP slow-start ramp-up, and calculates the sustained 85th percentile bandwidth under steady saturation. Both idle latency and loaded bufferbloat are measured in real time.

🔒Privacy

No account and no tracking. The test only exchanges anonymous measurement frames with the edge CDN; nothing is stored or shared.

💡Tips
  • For the most accurate result, close heavy background streaming or downloads.
  • Wi‑Fi speed varies with distance and channel congestion — test near the router for your line's true capacity.
  • Speed tests measure end-to-end throughput to the nearest cloud edge data center.
