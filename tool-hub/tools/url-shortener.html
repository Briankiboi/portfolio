⚙️How it works

Each shortened link is generated locally — an alias you choose, or a random 7-character base-62 code — and stored together with the long URL in this device's localStorage history (up to 50 entries). The short URL is simply this page's address followed by ?go=code: opening it reads the code, looks up the stored target and redirects you. Custom aliases and an optional client-side password hint are supported, and the history can be cleared or managed row by row.

🔒Privacy

Short links and their targets are stored only in this device's local storage — nothing is uploaded to any service.

💡Tips
  • A generated ?go=… link resolves instantly from this page, so share it across devices only while the folder is being served (e.g. a hosted copy or python3 -m http.server).
  • On file://, everything works offline and stays on the same device.
  • Custom aliases are faster to type and more memorable; alphanumerics, - and _ are kept.
