⚙️How it works

Enter a website URL or paste the page's HTML, then run the audit. The tool analyzes the page and generates four detailed reports from the same page.

  • 1 · Website Audit - get an overall score out of 100 based on important on-page website factors. The audit checks elements such as the page title, meta description, headings, images, links, canonical URL, Open Graph data, viewport, language, robots settings, content, and page structure.
  • 2 · SEO Validation - review important SEO elements one by one with a clear Pass, Warn, Fail, or N/A result. Each check explains what was found, why it matters, and what you can do to fix or improve it.
  • 3 · Broken Link Report — find and review links found on the page. Links are grouped as Working, Redirect, Broken, Blocked, or Internal, with response information where available. You can also export the results as a CSV file.
  • 4 · Core Web Vitals - check key performance and user-experience metrics for mobile and desktop, including LCP, INP, CLS, FCP, and TTFB where available. Use the results to identify pages that may need performance improvements.
  • 📊 One audit, four reports - run the audit once and review each report separately using the available tabs. Each report can be downloaded as its own CSV or summary where supported.
🔒Privacy

Your audit runs in the browser whenever possible. No audit data is stored on our servers. If direct access is blocked, a relay may be used to retrieve the page for analysis.

💡Tips
  • Use the full website URL for the best results.
  • Fix Fail and Warn items first.
  • Check Core Web Vitals for performance issues.
  • Blocked links are not necessarily broken.
  • Run the audit again after making improvements.
