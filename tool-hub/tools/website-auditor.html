⚙️How it works

Fetches the URL live (or parses HTML you paste) with DOMParser and runs 16 weighted on-page checks: title, meta description, viewport, Open Graph, Twitter cards, canonical, H1/H2, image alt, internal vs external links, script/link counts, HTML lang, robots meta, duplicate titles, word count and text/HTML ratio. Each check earns points toward a score /100 with a grade (Excellent / Good / Fair / Poor), a full checklist with details, improvement tips and a copy-ready report export. To get the page, the tool first tries a direct fetch from your browser; when CORS blocks that, it automatically retries through a public CORS relay (r.jina.ai, then api.allorigins.win).

🔒Privacy

The page is fetched directly from your browser when possible — no server involved and nothing stored. Only when CORS blocks that does the tool relay the request through a public CORS relay, which simply forwards the page's HTML back to your browser. For a fully private path, paste raw HTML instead and no request is made at all.

💡Tips
  • Grade bands: 85+ Excellent · 70+ Good · 50+ Fair · below Poor.
  • The tool auto-retries through a public CORS relay when direct reads are blocked — if even that fails (or you want zero third-party contact), paste the page's HTML (View Source → Copy) and re-run.
  • Pair this with the SEO Validation tool for a two-pass sanity check.
