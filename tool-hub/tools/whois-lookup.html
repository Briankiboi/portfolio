⚙️How it works

Enter a domain name to query its registration details through public RDAP, the modern replacement for WHOIS. The tool automatically finds the correct registry for the domain extension using the IANA RDAP registry.

It displays the registrar, creation, update, and expiry dates, domain status, nameservers, and available contact information. The complete RDAP response is also shown as raw JSON on the page, with an option to open it in a new tab.

🔒Privacy

Only the domain name you enter is sent to the relevant public RDAP registry. Nothing is stored or tracked, and the lookup runs in your browser.

💡Tips
  • Contact details marked "Redacted (GDPR)" are hidden by the registrar's privacy policy.
  • Each domain extension has its own RDAP provider.
  • .com and .net domains use Verisign, while other extensions use their respective registry operators.
